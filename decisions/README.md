# Decision records

One file per decision. Each one says what we decided, when, why, and what it costs. If you want to reverse a decision, write a new record that replaces it; don't edit history.

Our full decision register lives in Fibery (39 decisions as of 2026-11-03, covering product scope, monetisation, GTM, trust and fundraising). These four are written out in full as examples.
